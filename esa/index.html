GitHub 文件加速

粘贴链接，秒开下载 · release / 源码包 / 单文件

支持的地址

  • releases/download release 附件
  • archive 源码包（zip / tar.gz）
  • blob / raw 单文件
  • gist 代码片段
  • git clone 加速

使用提示

  • 链接带不带 https:// 都行
  • 右键「复制链接地址」最准确
  • 不支持整个文件夹，请用 archive
  • 大文件走流式转发，不占内存
基于 Cloudflare / EdgeOne / ESA · liyixin21/gh-proxy
