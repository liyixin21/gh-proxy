GitHub 文件加速

快速下载 GitHub 上的文件、发布和存档

使用说明

输入 GitHub 文件链接（带或不带协议头均可），支持 releases、archives 和文件

右键复制出来的链接通常都符合标准

注意：不支持项目文件夹的直接加速

合法输入示例

分支源码：https://github.com/liyixin21/project/archive/master.zip

release源码：https://github.com/liyixin21/project/archive/v0.1.0.tar.gz

release文件：https://github.com/liyixin21/project/releases/download/v0.1.0/example.zip

分支文件：https://github.com/liyixin21/project/blob/master/filename

项目基于 Cloudflare Workers，开源于 GitHub liyixin21/gh-proxy ，基于 hunshcn/gh-proxy 修改
